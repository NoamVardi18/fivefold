# הבוסית במשקפיים / Cool Baby

סדרת אנימציה עם AI ללקוח פרטי. הפורמט הוא פרקים מלאים, אופקיים (16:9), של 3–4 דקות.

**להתחלה:** פותחים סשן Claude Code בתיקייה הזו ומדביקים את התוכן של `START-HERE-SESSION-PROMPT.md`.

| קובץ | מה יש בו |
|---|---|
| `START-HERE-SESSION-PROMPT.md` | פרומפט פתיחה לסשן מקומי: מחקר עדכני (/last30days), בדיקת המחשב, בניית תבנית Remotion ושיפור התוכנית |
| `CLAUDE.md` | כללים לכל סשן |
| `docs/PLAN.md` | התוכנית המלאה, והמסמך הקובע |
| `docs/plan.html` | התוכנית כדף אינטראקטיבי עם כפתורי העתקה (גרסה קודמת, לפני המעבר ל-16:9). אונליין: https://claude.ai/artifact/CffN4icsfHCU75kxjQZ8kn |
| `docs/RESEARCH.md` | ממצאים, קישורים, ומה לא אומת |
| `docs/DECISIONS.md` | יומן החלטות |
| `prompts/` | פרומפטים להעתקה: DNA, דפי דמות, לוקיישנים, תמונות מפתח, וידאו, תסריט, מוזיקה, קריינות |
| `episodes/EP01-hat/shotlist.md` | שוט ליסט מלא לפיילוט המומלץ, כ-3:30 |
| `editing/REMOTION-SPEC.md` | מפרט לתבנית העריכה, שהסשן המקומי יבנה |
| `references/README.md` | הערות על תמונות הרפרנס. התמונות עצמן לא נכנסות ל-git. |

⚠ פרטיות: תמונות אמיתיות של הילדה לא נכנסות ל-git ולא מתפרסמות. הן נשמרות ב-`references/photos/`, והתיקייה הזו מוחרגת ב-`.gitignore`.
